# 🚀 TONET

<p align="center">
  <img src="https://img.shields.io/badge/PROJECT-TONET-ff2020?style=for-the-badge&labelColor=080808" alt="TONET project" />
</p>

> **Uma plataforma para conectar artistas, criadores, fãs e empresas.**

O **TONET** é um projeto de longo prazo desenvolvido em equipe. A proposta é criar um espaço onde artistas possam apresentar seu trabalho, construir portfólios, mostrar suas habilidades e encontrar novas oportunidades.

### ✦ O que a plataforma busca possibilitar

- 🎨 Apresentação de trabalhos e portfólios
- 🏷️ Tags para destacar habilidades e áreas de atuação
- 🔎 Descoberta de artistas
- 🤝 Colaborações entre pessoas
- 💼 Oportunidades de trabalho e projetos
- 🎤 Eventos e apresentações
- 🎹 Aulas e serviços artísticos
- 💬 Conexões entre artistas, clientes, empresas e fãs
