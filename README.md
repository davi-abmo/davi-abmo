# 🔥 TONET

<div align="center">

### O melhor amigo de qualquer artista.

</div>

O **TONET** é uma plataforma que estou desenvolvendo em equipe para conectar **artistas, criadores, fãs e empresas**.

A proposta é ajudar artistas a apresentarem seu trabalho, encontrarem oportunidades, colaborarem com outras pessoas e serem descobertos.

### ✦ O que o TONET busca oferecer

- 🎨 Portfólios para apresentação de trabalhos
- 🏷️ Tags para destacar habilidades e áreas de atuação
- 🔎 Descoberta de artistas
- 🤝 Colaboração entre pessoas
- 💼 Oportunidades de trabalho e projetos
- 🎤 Eventos
- 🎹 Aulas
- 💬 Conexão entre artistas, clientes, empresas e fãs

O TONET é um **projeto de longo prazo desenvolvido em equipe**.
